Extension: Registreringsstatus

Officiell URL: https://fhir.inera.se/ig/engagementindex/StructureDefinition/RegistrationStatus Version: 0.1.0
Draft per 2026-10-26 Beräkningsbart namn: RegistrationStatus
Andra identifierare: RegistrationStatus

Postens exakta livscykeltillstånd: registrerad, indragen eller felregistrerad. Bär den semantik som DocumentReference.status inte kan uttrycka, eftersom basbindningen inte kan utökas.

Context of Use

    Denna extension kan användas på följande element

    • Element-ID: DocumentReference

Usage info

Användningar:

  • Använd denna Extension: Indexpost (FHIR-EI)
  • Exempel för denna Extension: Bundle/RegistreringTransaction, Bundle/SokresultatForPatient, DocumentReference/IndexpostEjForPatient, DocumentReference/IndexpostFhirProducent... , DocumentReference/IndexpostFranAdapter and DocumentReference/IndexpostIndragen

Du kan också kontrollera användningar i FHIR IG-statistiken
