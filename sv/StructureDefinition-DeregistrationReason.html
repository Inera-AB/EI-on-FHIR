Extension: Orsak till avregistrering

Officiell URL: https://fhir.inera.se/ig/engagementindex/StructureDefinition/DeregistrationReason Version: 0.1.0
Draft per 2026-10-26 Beräkningsbart namn: DeregistrationReason
Andra identifierare: DeregistrationReason

Varför posten avregistrerades: felregistrering, avslutat engagemang, gallring eller avregistrering via övergångsadaptern. Finns om och endast om posten inte är registrerad.

Context of Use

    Denna extension kan användas på följande element

    • Element-ID: DocumentReference

Usage info

Användningar:

  • Använd denna Extension: Indexpost (FHIR-EI)
  • Exempel för denna Extension: Bundle/RegistreringTransaction and DocumentReference/IndexpostIndragen

Du kan också kontrollera användningar i FHIR IG-statistiken
