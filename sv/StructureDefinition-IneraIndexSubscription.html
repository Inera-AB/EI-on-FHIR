Resursprofil: Prenumeration på indexposter (FHIR-EI)

Officiell URL: https://fhir.inera.se/ig/engagementindex/StructureDefinition/IneraIndexSubscription Version: 0.1.0
Draft per 2026-10-26 Beräkningsbart namn: IneraIndexSubscription
Andra identifierare: IneraIndexSubscription

En konsuments prenumeration på ändrade indexposter, på topic indexpost-andrad. Prenumerationen kan filtreras på patient, tjänst och vårdgivare. Notiser bär bara id för ändrade poster, så att de inte bär mer patientinformation än nödvändigt.

Användningar:

  • Exempel för denna Profil: Subscription/PrenumerationForPatient
  • CapabilityStatements som använder denna Profil: FHIR-EI server

Du kan också kontrollera användningar i FHIR IG-statistiken
